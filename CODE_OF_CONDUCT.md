# Code of Conduct

Legacy Doctor handles storage media that may hold irreplaceable data. Contributors and maintainers are expected to work in a way that is respectful, careful, and honest.

## Expected behavior

- Be respectful and assume good faith in reviews, issues, and discussions.
- Give and accept specific, technical, constructive feedback.
- Report failures, uncertainty, and unproven claims plainly. Do not present a producer claim as proof.
- Never encourage anyone to test destructive behavior on media that holds valuable data.

## Unacceptable behavior

- Harassment, discrimination, personal attacks, or doxxing.
- Publishing another person's private data, raw disk images, credentials, serial numbers, or receipts that contain machine paths.
- Deliberately misleading receipts, test results, or documentation.

## Enforcement

Maintainers may edit, reject, or remove contributions, comments, and issues that violate this policy, and may restrict participation. Report conduct concerns privately to the repository maintainers through a private GitHub security advisory or the maintainer's GitHub profile contact. Reports are handled in confidence where possible.
